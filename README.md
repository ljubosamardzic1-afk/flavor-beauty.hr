# FAVOR Beauty Salon

Jednostranična stranica za FAVOR Beauty Salon (Sonja), Poljička cesta 51, Split.

## Objava na GitHub Pages (najlakši način)
1. Skini `favor-standalone.html`.
2. Preimenuj je lokalno u `index.html`.
3. Napravi novi repozitorij na GitHubu → Add file → Upload files → prevuci tu jednu datoteku.
4. Settings → Pages → Source: Deploy from a branch → main / (root).
5. Stranica je za minutu-dvije živa.

Sve slike su ugrađene unutar te jedne HTML datoteke, pa nema foldera koji se može izgubiti pri uploadu.
